# CyberCTF

CyberCTF is an organization that builds capture-the-flag (CTF) labs. Its labs are described as deployable environments (Docker, VM, home lab, AWS) and are run with Isoloom.

## Public repositories

- **Lab-Template**: The single CyberCTF lab template: one compose file, every target (Docker, VM, home lab, AWS)
- **dracarys**: DRACARYS (Game of Active Directory), run with Isoloom
- **minilab**: MINILAB (Game of Active Directory), run with Isoloom
- **goad-mini**: GOAD-Mini (Game of Active Directory), run with Isoloom
- **goad**: GOAD (Game of Active Directory) full lab, run with Isoloom
- **goad-light**: GOAD-Light (Game of Active Directory), run with Isoloom
- **invoice-portal-api**: Supplier portal API: a CyberCTF lab (read an authenticated REST API)
- **publish-lab-action**: Hardened GitHub Action that registers a CyberCTF lab with the catalogue (endpoints live here, not in public lab repos).
